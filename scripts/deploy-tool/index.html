Marketplank Vault — owner-signed deployment

This page runs entirely in your browser. It never asks for a private key. Every transaction is built here and sent to window.ethereum for YOUR wallet to sign — nothing leaves this tab except what your wallet broadcasts once you approve it. It is not part of the production site and is never deployed to plank.love. Run it over a local HTTP server — most browsers block the contract JSON fetch under file:// (CORS). From this directory: npx serve . (or python -m http.server 8000), then open the printed http://localhost:… URL.
Before you do anything else: contracts/MarketplankVault.sol and contracts/DrandBeacon.sol have not had an independent third-party audit. See docs/marketplank/AUDIT-2026-07-27-fable.md. Deploying is your decision to make as the owner, not something this tool decides for you.
