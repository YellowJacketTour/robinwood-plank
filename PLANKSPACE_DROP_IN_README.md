# PlankSpace drop-in update

This archive is rooted at the RobinWood project directory. Extract it over
the same directory that contains `package.json`; allow files to be replaced.

## What this update fixes

- PlankSpace reuses the root Plank.love wallet state and waits for Reown to
  restore an existing WalletConnect session before showing another connector.
- Profile authorization uses the exact safe EIP-191 verification message
  generated by the server, then reuses the resulting 12-hour session token.
- Empty or non-JSON authentication responses now produce a useful error rather
  than `Unexpected end of JSON input`.
- PlankSpace brand links use Next.js client navigation and return to
  `/plankspace` without leaving the combined app.
- The Profile Workshop action has an explicit visible, accessible button style.
- Migration `033_plankspace_profile_seed_repair.sql` restores all canonical
  profiles, DegenWaffle's page data, default friendships, and Top 8 while using
  conflict-safe inserts so later owner edits are not overwritten.

## Required after extraction

```powershell
npm install
npm run build
git add --all
git commit -m "fix: restore native PlankSpace wallet and profiles"
git push vercel-test HEAD:plankspace-test
```

The migration requires the same `PGHOST`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`,
`PGPORT`, and `PGSSLMODE` values used by the deployed application. Add those
variables to Vercel Preview as well as local `.env.local`. Do not put their
values in Git.

For a Vercel Preview database, first connect a PostgreSQL/Neon store to the
Vercel project with **Preview** enabled. Then pull that preview environment and
apply the migrations to that same database:

```powershell
npx vercel link
npx vercel env pull .env.preview.local --environment=preview
node --env-file=.env.preview.local scripts/migrate-postgres.mjs
```

The server accepts either Vercel-style `POSTGRES_URL` / `DATABASE_URL` or the
individual `PGHOST`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`, `PGPORT`, and
`PGSSLMODE` variables.

Vercel also needs `NEXT_PUBLIC_WALLET_UI=reown` and the existing
`NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` so Plank.love and PlankSpace use the
same root Reown connector.
