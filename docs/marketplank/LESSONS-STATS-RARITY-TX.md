# Lessons — stats, rarity, transactions

Append-only. Each lesson is a synergy: specialize first, then reuse.

## 2026-08-20

1. **OpenSea BNB list ≠ book.** Pancake Squad and OS `bsc` slugs often 404 `/stats`. CoinGecko `/nfts/list?asset_platform_id=binance-smart-chain` + exact `contract_address` is the liquid book (Mobox Avatar, XENFT, etc.).
2. **Do not increment monthly CG quota on list pages.** Jail key `coingecko-nft-monthly-v2`; details only. False 9000 jail killed BNB for a session.
3. **Unknown zeros.** Storing empty OS intervals as `0` paints a dead book. `sanitizeUnknownZeros` + COALESCE floors. Heal then re-vine.
4. **Identity filter hid real catalogs.** Chip counts must keep UniSat/ME/Helius/Ordiscan even with empty titles. Spam prune only when no floor/listed/vol/holders/supply.
5. **Alchemy adapter on CG upserts.** New BNB rows with `adapter: alchemy-nft` get skipped by `multichain-sync` when Alchemy is jailed. Use `coingecko-nft`.
6. **`--chains=` on stats.** Running all EVM then 429 burns ETH quota and skips OP. Isolated processes per vine.
7. **RobinWood local empty book.** Overlay `plank.love` canonical (0.019 Ξ / 105 listed) — do not invent.
8. **Hub GET is read-only.** Hydrate/stats/rarity writers are separate routes/scripts so `/market/multichain` cannot hang the table.
9. **Rarity Bitcoin is always partial.** UniSat activity log is not a full inscription walk. Partial rank > fake complete.
10. **Foreign fulfill allowlist.** Wallet `to` must match venue contracts. No custody, no Across/0x Instant Swap on foreign.
11. **Synergy:** same exact-match kernel for CG (contract or id), OS named slug, ME symbol→mint, UniSat collectionId. Fuzzy attach is worse than a dash.
12. **Optimization:** one paced CG worker beats ten concurrent pages. Site stays up if Next is detached (`START-MARKET.bat`).
13. **`--spoke=coingecko-avax` was a no-op** until `spoke-backfill.ts` grew a `want("coingecko-avax")` branch. Cron steps and spoke IDs must stay in lockstep or workers silently finish in 0.1s.
14. **Same first 15 forever.** CG jobs used to slice `matches.slice(0, maxUpdates)` from tracked-then-catalog order, and catalog upserts stopped at `maxUpdates * 2`. Collections already floored were re-hit. Now: missing-floor first, catalog cursor, skip hasFloor, platforms for ETH/Polygon/Base/Arb/OP too. `scripts/fill-all-collection-stats.ts` walks OS + CG + ME/UniSat until the clock.
15. **CG monthly v2 read 164937** (false list-page increments from the old key path). Detail writes are skipped until a new month or a deliberate counter reset. Do not upsert CG catalog shells while the cap is spent.
16. **Bitcoin hub art.** 2497 UniSat rows, 59 images. Names missing → truncated collectionId (`bitcoi…ooms`). `ordinals.com/content/{id}` is ORB-blocked in the browser; CollectionThumb must proxy via `/api/ipfs/image`. UniSat `/collection_statistic` 500s for many ids; `/collection_statistic_list` still has icon+name — backfill from the list, exact collectionId only.
17. **Never stall on one vendor.** Live 2026-08-20: UniSat 403 rate limit, Ordiscan 429 monthly 1000, ME BTC 403 CF, CG `/nfts/markets` PRO-only 401, CG `/nfts/{id}` Demo still 200. v2 monthly KV was a false jail (164k). v3 details-only. Rotator: OrdinalsWallet turbo exact-slug (keyless) → CG detail → UniSat if not jailed. Persist jail in KV. 404 caches none. One 403 does not stop the pass.
18. **Hero blur.** CG `small` ~6KB; `/large/` on coin-images is a real 200 ~98KB. OW `inscription/preview` 404s; full bytes are `ordinals.com/content/{id}`. Hub thumbs walk large → 2x → original → preview. Inscriptions use `image-rendering: pixelated` so 64px on-chain art is not bilinear-smeared across the hero. Proxy width tier 2048 for hero. Fail last candidate only — not the whole collection.
19. **All chains, same rotator discipline.** Art+stats hydrate is source-rotated: ME stats-search (Solana exact symbol, keyless) + OW/CG (Bitcoin) + OS display (EVM) + CG exact contract when OS 404s. `CollectionArtImage` is shared by hub, collection header, listings. Seadn `w=2000` before `w=500`. One 403 never ends the pass.
20. **Mesh constitution.** `docs/marketplank/SPEC-SYNC-MESH.md` + `lib/market/multichain/mesh/matrix.ts`. A contribution is a new **lane** (source×chain), never a second all-chains process. `npm run market:mesh` spawns isolated `mesh-lane` children; jailed source exit 0. Test: `test/market/mesh-matrix.test.ts`.
21. **RobinWood art vanished.** `imageSrcFallbacks` only accepted `http(s)`, so `/images/plank-logo.webp` (and `/api/ipfs/…`, `ipfs://`) produced zero candidates and CollectionArtImage showed the placeholder. Same-origin and ipfs URIs must stay first-class. Test: `test/market/collection-art.test.ts`.
22. **Milady grid blank + all Legendary.** Tokens route preferred the rarity index and **hardcoded imageUrl:null**. A giant score-tie used the first row's 100th-percentile so every piece was Legendary. Official-tier detection must be exact labels, not substring "rare". Persist `image_url` on index; merge OS/ME/OW when null; recompute collapsed tiers from trait_index.
23. **Rarity-sorted ids ≠ collection NFT page order.** Filling from OS `/nfts?limit=50` never hits token 6770. Resolve **this page's token ids** (proven CDN template, then OS `/nfts/{id}`). Recompute tiers with UPDATE not DELETE so art columns survive. Add a template only after a live 200 on that host.
24. **Proxying miladymaker.net broke the PNGs.** ORB proxy is only for hosts that fail as raw `<img>`. Direct `https://www.miladymaker.net/milady/{id}.png` works (200). Client must apply the template even when the tokens SWR cache is stale. Sidebar tier counts must use the **catalog**, not only listings (listed-only counts showed Epic 0 while the grid was Epic).
25. **Rarity menus looked broken because the catalog was rank-sorted.** First 200 of 9879 are all Legendary. Filters for Epic/Common then matched nothing. Default order is token id; `?tier=` and `?sort=rank` refetch. Floor chips stay clickable when the loaded book has 0 of that tier but the catalog does. Shared `rarityMapGet` for listings vs index keys.
26. **Listings/prices vanished on All items.** Overlay used `filteredListings` + exact `tokenId` string. Book `6770` vs catalog `06770` missed; extras dumped as empty cards. Overlay from **raw listings** via `tokenIdAliases`. Listed view stays **price-asc**. Rarest-first sorts **tier band** (Legendary→Common) then rank.
27. **Two grids were racing.** All-items prepended the 50 cheapest listings then token 0,1,2 — ranks, prices, and filters collided. Catalog is the grid; the book only **overlays** Buy/price on matching ids. Listed-only is the book. Do not reindex when sample already ≥6k. Load more raises the catalog window (400→2000). Listings fetch 200 so floor-by-rarity sees more of the book.
28. **Milady-quality is the collection surface.** `collection-surface.ts` per chain: catalog page/cap, book size, art extras. Client never imports pg. New chain = new surface row, not a second grid.
29. **Empty `collections: []` is not a good SWR hit.** `isGood` only checked Array.isArray, so a 503-recovery or empty index locked the hub blank for 10 minutes in sessionStorage. Require `length > 0`. `invalidateSwr` must drop session keys too. Global is `/market/multichain` (same BUY & SELL rail as native). Native `/market` empty book ≠ Global down. START-MARKET.bat owns Next, not Grok.
