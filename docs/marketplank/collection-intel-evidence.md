# Collection intelligence: evidence and visual verification

The collection Intel view uses each collection's own artwork within a neutral graphite and violet interface. No collection mascot or scenery is applied globally.

The first view contains a timestamp/price observatory, selected transaction and token traits, cumulative asking-price depth, and trait asking-premium comparisons. Native sale evidence remains visible when USD conversion is unavailable. Sale and ask payment currencies are isolated. Venue duplicates count once per token; equal-price asks include all pieces at that price. Original decimal amounts remain available for inspection and CSV exports escape quoted text and formula prefixes.

SVG replaces the time/price chart's WebGL context, removing a reproduced blank-context failure. Additional diagnostic charts mount only when expanded. Empty artwork uses a safe accent fallback. Source links retain provenance; unobserved data is not presented as zero or complete coverage. The dossier renders immediately and describes loaded records rather than claiming comprehensive knowledge.

The parent collection view folds source/archive details in Intel mode, removes the unused filter column and buy controls, and restores them when returning to listings. No trading authorization or contract changes are included.

## Verification

- Four independent dream-loop reviews progressed from 5.8 to 8.0/10; the last review met the skill's visual threshold for the user's requested neutral adaptation.
- Browser checks exercised native-only evidence, interval selection, exact chronology, trait selection, and the integrated collection route with absent artwork/history. Returning to listings restores the filter panel and source statistics.
- A populated fixture was used only locally and is excluded from the production routes and release.
- Initial mobile check at 390px found no horizontal document overflow. Final SVG view creates no Intel chart canvases while diagnostics are collapsed.
- Regression tests cover missing USD conversion, currency isolation, native precision, future dates, duplicate asks, equal-price cumulative depth, case-sensitive non-EVM wallets, and safe CSV cells.

Source completeness remains a separate ingestion concern: these visualizations accurately describe the available evidence and do not imply every venue or historical block has been indexed.
