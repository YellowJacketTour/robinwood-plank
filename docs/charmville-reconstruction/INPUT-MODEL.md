# Input model: keyboard, touch and gamepad

One action uses one server command regardless of input device. Menu navigation never creates a second economic or combat path. This checkpoint improves menu access; it does not certify every physical device or every planned action.

| Intent | Keyboard | Touch | Standard gamepad |
|---|---|---|---|
| Adventure movement | Arrow keys | Existing on-screen directions | D-pad / left stick |
| Sword / equipped item | Z / X defaults | Existing action buttons | Configurable face buttons |
| Open native Game menu | Enter | Game menu button | Start |
| Menu selection | Arrows; Tab across groups | Tap visible option | D-pad / stick |
| Confirm | Enter or Space on buttons | Tap | South (A / Cross) |
| Return from native menu | Escape / Back | Back | East (B / Circle) |
| Return from account menus to play | Play tab | Play tab | East |
| Capture | Game menu → Throw ball | Same visible option | Same menu option |

Availability comes from the same authenticated capture command. A disabled option is not a second way to bypass range, control, inventory or retry checks. The native renderer owns input while its frame is focused. The parent menu adapter only acts with parent focus, and waits for neutral on transitions or reconnection. Held confirm cannot spill into a sword action. Text entry is not controlled by gamepad navigation.

Party slots and Summary/Care/Organize use one Tab stop per group, arrows and Home/End. Native menu direction uses actual positions, so disabled options do not distort the grid. Face-button remapping cannot overlap reserved movement/menu/shoulder buttons; assignments are unique. South/East remain the menu convention regardless of gameplay mapping.

Verification distinguishes browser-injected standard gamepads from real hardware. Keyboard/mobile-width browser tests and synthetic-controller checks provide evidence for input logic, not Bluetooth pairing, controller-specific drivers, mobile browser fullscreen support or every touchscreen. Voice recording remains explicit; input transitions must not start recording automatically.
