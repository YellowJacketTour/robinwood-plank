# Attack source verification

Run `node scripts/charmville/verify-attack-source-integrity.mjs` from the repository root. This read-only check verifies all 18 preserved attack PNG hashes against the pinned source catalogue, all eight directional sheet dimensions, and animation durations and contact frames against each species' XML. It checks 504 directional attack frames across the six currently supported companions. It never regenerates the expected evidence during verification.

These checks protect source integrity; they do not certify artistic quality. The existing PMD Attack sequences are explicit presentation mappings for supported moves, not Emerald's complete move effects. New moves need their own source mapping, timing, target effects and directional review. A source repository does not by itself grant rights to every contributed asset.

For each playable action, acceptance requires: recognizable anticipation; consistent facing and ground anchor; tool or creature contact aligned to the intended target; one committed result; recovery; cancellation on changed encounter or map; and correct overlap with terrain and nearby characters. Defeat must follow queued attack presentation. Multiplayer viewers must receive the same committed result without replaying history after reconnect. Keyboard, touch and controller access must reach the same action.

Outstanding visual coverage includes authored directional hero throw poses, per-move elemental and status effects, complete eight-direction playback review, large-creature footprints, terrain occlusion, and multi-party positioning. Those remain work, rather than inferred completion from the source catalogue.
