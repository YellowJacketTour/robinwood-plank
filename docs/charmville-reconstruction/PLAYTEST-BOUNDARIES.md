# Playtest boundaries

Use the retained local playtest browser instance and simulated account. Do not request, inspect or use the owner's seed phrases, private keys, or wallet credentials. Do not sign or submit blockchain transactions. Wallet-related gameplay may be simulated; clearly distinguish simulated balances, custody and confirmations from real transactions. Ordinary game inventory operations on the local test account remain available.

Reuse the same browser tab unless it is closed or unavailable. Preserve its session. If it is gone, report that fact rather than claiming live observation. A newly opened tab may require the local launcher because the local account session is tab-scoped.

Report evidence at its actual level: source inspection, unit checks, native compilation, browser UI interaction, visible gameplay, multi-client simulation, or external multi-player testing. These are not interchangeable. Do not claim a rendered effect from a compile, or shared combat from connected presence.
