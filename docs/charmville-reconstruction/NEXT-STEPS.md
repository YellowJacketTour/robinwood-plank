4. **Curated item and art catalog.** Ingest source item IDs/names/icons/animations/tool behaviors/map entity references, not just filenames. Include source revision, reference profile, animation states/directions/origins, equipment slot, verb set, collision rules, provenance, transformation lineage, custom-art replacement status. Keep canonical Charmville identity distinct from source IDs. Group complete coherent art sets: woodland, settlement, interiors, grass/water, hero actions, monsters, crop stages, tools, hearts, inventory, battle screens. Review actual art, avoid mixed perspective/palette placeholders.
5. **First combined playable woodland.** Preserve reference hero movement and combat. Add farmland as explicit stateful entities with till/plant/water/grow/harvest stages, item costs and yields. Integrate experience/skill unlocks and one original-source-derived creature encounter/capture. Working portals must roundtrip player state. Every demonstrated mechanic gets a visible consequence, and save/reload retains it.
6. **Two authenticated players and durable authority.** Reuse PlankSpace identity; server validates movement/action intent and all scarce item mutations. Transactional inventory/action receipts, idempotency, out-of-order handling, reconnect recovery, concurrent harvesting, trade reservation and no duplication. Do not treat localStorage as authority. Keep untrusted reference runtimes separate from wallet credentials. Do not add Redis contrary to existing project policy; assess PostgreSQL-based boundaries and existing services first.
7. **Economy/social vertical slice.** One coherent charm identity used in world, inventory and a post reaction. Define expression vs consumption vs scarce issuance. Bounded rewards, sinks/composting, listing/reservation/cancel/fill, atomic delivery, fees, order history. Grained Exchange UX draws from OSRS/EVE. Real DeFi requires chain/pool verification, simulation, safeguards and audited settlement before any real-money claims. Never infer balances/prices from the archived memoji registry.
8. **Production/settlement/civilization.** Crafting dependency graph, gear/skills, land ownership/permissions, resource logistics, communal projects, NPC services and SimCity civic effects. Deliberate simple starting loop with deeper specialization; avoid dozens of nonfunctional tabs masquerading as systems.
9. **Community authoring and bespoke reconstruction.** Versioned asset packs and schema validation, canonical origins/scales/actions, editor import/export, previews, permissions, moderation, provenance and replay-based regression. Replace reference visuals/item by item while preserving behavior. Modern 3D events and strange regions remain stylistically consistent with daily 2.5D life.
10. **Polish/scale/operations.** Input latency, frame pacing, touch/gamepad, readable UI/accessibility, audio, performance budgets, shard/region transitions, observability, backups, migrations, economy abuse controls and rollback/reconciliation. Final quality requires observed play and artistic approval, not just test counts.

For every milestone record: what the player can do, source/reference evidence, integration boundary, server vs local ownership, persistence behavior, tested browser/control paths, failures, screenshots and a verified URL. Leave a latest-state handoff and Git checkpoint at meaningful boundaries. Never say the full vision is finished while these gates are open.
