Why this is safe now

The old V2 tracked LP as flat credits, which let a one-sided add + a trade + a withdraw drain the pool. V3 mints proportional LP against the current reserves — a contributor absorbs any price move they cause, so there is nothing to extract.

Shares are pulled to match your ETH at the live ratio, so you never over- or under-supply a side. The slippage guard (minLpOut) protects large adds — the UI fills it from the live quote automatically.

Remove burns your LP for a pro-rata slice of whatever the reserves are then — including your share of accrued swap fees.

C · The five actions (all V3)
Buy / Sell

ETH ⇄ shares

Constant-product swap with a 0.30% fee that goes to LPs (grows the pool). Rate, fee, price impact and minimum-received shown before the CTA.

Deposit / Redeem

Plank ⇄ share flat ETH fee

Deposit a plank → exactly one share for a flat ETH fee. Redeem a share → a plank (random via drand, or targeted for an ETH premium). No 0.99/1.01 dust — V3 mints and burns whole shares.

Liquidity

Add / remove proportional

The section B card. Proportional LP tokens, pro-rata withdrawal, LPs earn the swap fee. The reason to hold liquidity at all.

Migration

V1/V2 never appear here

The swap page is V3-only. A wallet holding a retiring vault sees the prompt at the top and the site-wide banner, both routing to /migrate. Nothing on this page promotes the old vaults.

D · States
Disconnected

Connect to trade

The form is disabled with a single "Connect wallet" CTA; vault-at-a-glance and analytics still render from public reads. No wall of empty boxes.

Loading

Skeletons, not blanks

Fixed-height pulse skeletons so the first paint has structure — the current page's worst tell is large empty bordered boxes while RPC resolves.

Pool closed / empty

Honest empty state

Before openPool(), or if a side is empty, the card says so instead of a dead form. Deposit/redeem still work when trading doesn't.

Holds V1/V2

Migration-first

The top prompt is shown and persists until the wallet's legacy balance is zero; the swap actions still target V3 underneath.

E · Why this beats today

Today: a ten-panel vertical stack (dual-vault switcher, swap panel, the big living-liquidity circle, vault book, price chart, redeem odds, trade history, migrate details, seed, treasury), mostly dense data fighting for attention, with large empty boxes while it loads — and it promotes the drained V2.

This: a single V3 vault line, a focused trade card with the five actions in one control, a context column (your position + vault-at-a-glance, both with real plank art), and one tabbed area for chart / odds / activity / liquidity. Operator tools (seed, treasury) move behind an "Operator" disclosure, off the trading path. V1/V2 are gone from the page entirely — only the migration prompt references them.
